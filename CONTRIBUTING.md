# Contributing to HouseGhost

Thank you for your interest in contributing to HouseGhost!

---

## Development Guidelines

### 1. Fork the Repository
* Fork the repository on GitHub and clone your fork to your local machine.

### 2. Create a Feature Branch

```bash
git checkout -b feature/your-feature-name
```

### 3. Development Rules
* Maintain clean, readable, and consistent code formatting.
* Ensure zero telemetry, analytics, or external tracking code is introduced.
* Maintain 100% Manifest V3 compliance.
* Preserve full Netflix native player control interactivity (scrubber, subtitles, audio, episodes).

### 4. Test Locally
* Open `chrome://extensions` (or `edge://extensions`) in your Chromium browser.
* Enable Developer mode and click **Load unpacked**.
* Select the `HouseGhost` folder and verify UI layouts.
* Test on Netflix playback to confirm seamless bypass without control blocking.

### 5. Submit a Pull Request
* Commit your changes with a descriptive commit message.
* Push your branch and open a PR against the `main` branch.
